Formiga de Langton

Duas regras, um tabuleiro, e um comportamento que até hoje ninguém conseguiu provar.

Clique na grade para mudar a cor de uma célula antes de rodar (ou no meio da execução) e ver como a formiga reage a um tabuleiro que não começa vazio. Atalhos: espaço roda/pausa, → +1 passo.

A grade tem 256×256 células e as bordas se conectam (é um toro): quando a estrada chega à borda, reaparece do outro lado e acaba esbarrando no próprio rastro.

As duas regras

A formiga fica numa célula, virada para uma das quatro direções. A cada passo ela olha a cor da célula onde está:

Célula apagadavira 90° à direita, acende a célula e anda uma casa.
Célula acesavira 90° à esquerda, apaga a célula e anda uma casa.

Não tem sorteio nem memória: o estado inteiro do sistema é a grade, mais a posição e a direção da formiga. Mesmo começo, mesmo filme, sempre. O modelo foi proposto por Christopher Langton em 1986, no contexto de vida artificial.

As três fases (partindo da grade vazia)

0 – ~500Simplicidade. Padrões pequenos, muitas vezes simétricos.
~500 – ~10.000Caos. Uma mancha irregular que cresce sem estrutura aparente.
~10.000 – ∞Estrada. Um ciclo de 104 passos que se repete para sempre e desloca a formiga 2 casas na diagonal a cada volta.

No simulador, o card "estrada detectada" acende quando o deslocamento a cada 104 passos fica constante (±2, ±2) por vários ciclos seguidos.

O que está provado (e o que não está)

Provado: ela nunca fica presa

Para qualquer configuração inicial, até com infinitas células acesas, a trajetória é ilimitada: a formiga sempre acaba se afastando tanto quanto se queira. O argumento, em resumo:

  • Como ela sempre vira 90°, os passos alternam entre horizontal e vertical. Pinte a grade como um tabuleiro de xadrez: nas casas de uma cor ela sempre chega por um passo horizontal, nas da outra, por um vertical.
  • Se a trajetória fosse limitada, algumas células seriam visitadas infinitas vezes. Escolhendo a mais extrema delas (por exemplo, a mais acima e depois mais à direita) e seguindo as regras, chega-se a uma contradição: ela teria que sair desse conjunto.

Esse resultado aparece em Bunimovich e Troubetzkoy (1992), uma das fontes do vídeo.

Não provado: a estrada sempre aparece

Toda simulação com um número finito de células acesas no começo terminou numa estrada. Mas ninguém provou que isso sempre acontece. É o "nenhuma prova" do título do vídeo.

Dois fatos curiosos

  • É reversível: dado o estado atual, dá para rodar as regras de trás para a frente e reconstruir o passado exato.
  • É universal: com o tabuleiro inicial certo, a trajetória da formiga pode simular circuitos lógicos arbitrários (Gajardo, Moreira e Goles, 2002). Então, em princípio, ela consegue computar qualquer coisa que um computador computa.

Generalização: mais de duas cores

Escreva uma regra como uma sequência de letras L e R. A letra na posição k diz para onde virar numa célula de cor k. Depois a célula avança para a cor k+1 (voltando a 0 no fim) e a formiga anda.

  • RL é a formiga clássica (cor 0 → direita, cor 1 → esquerda).
  • Regras feitas só de pares repetidos de letras (como LLRR) costumam gerar padrões simétricos.
  • Outras ficam caóticas para sempre (RLR) ou formam figuras geométricas que crescem.

Teste no seletor "Regra" ou invente uma (2 a 12 letras).

Reproduza em ~15 linhas

Python + NumPy + Matplotlib
import numpy as np
import matplotlib.pyplot as plt

N = 200
grid = np.zeros((N, N), dtype=np.uint8)  # 0 = apagada, 1 = acesa
x, y = N // 2, N // 2
d = 0                                     # 0=cima 1=dir 2=baixo 3=esq
DX, DY = [0, 1, 0, -1], [-1, 0, 1, 0]

for passo in range(11_000):
    if grid[y, x] == 0:
        d = (d + 1) % 4   # apagada: vira à direita
    else:
        d = (d - 1) % 4   # acesa: vira à esquerda
    grid[y, x] ^= 1       # inverte a cor
    x = (x + DX[d]) % N   # anda uma casa (bordas conectadas)
    y = (y + DY[d]) % N

plt.imshow(grid, cmap="Oranges")
plt.axis("off")
plt.show()

Para a versão com várias cores, troque o if por d = (d + (1 if regra[c] == "R" else -1)) % 4 e grid[y, x] = (c + 1) % len(regra), com c = grid[y, x] lido antes.
